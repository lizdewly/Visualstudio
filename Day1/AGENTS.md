# Agent Instructions

- This workspace contains small, standalone Python learning exercises. Keep changes focused and beginner-friendly.
- Preserve the simple procedural style and existing Korean comments or prompts. Avoid adding dependencies, frameworks, or abstractions unless the task requires them.
- Run an exercise from Windows with `py <filename>` (or `python <filename>` if the Python launcher is unavailable). `day2.py` reads console input.
- No test suite or dependency configuration is present. For a Python change, syntax-check the touched file with `py -m py_compile <filename>` and run it with representative input when practical.

## 학습 질문과 답변 기록

- 이 프로젝트에서 사용자가 묻는 AI, 파이썬, 코딩 관련 학습 질문과 답변은 답변을 마무리하기 전에 `glossary/`에 Markdown 문서로 기록한다. 사용자가 기록하지 말라고 한 내용은 제외한다.
- 먼저 `glossary/README.md`와 기존 관련 문서를 확인한다. 새 주제는 `glossary/TEMPLATE.md`를 참고해 `YYYY-MM-DD-짧은-주제.md`로 만들고, 같은 파일명이 있으면 숫자를 붙여 구분한다. 날짜는 사용자 시간대(Asia/Seoul)를 따른다.
- 질문은 의미를 보존해 적고, 답변은 초보자가 복습할 수 있도록 한국어로 정리한다. 필요한 경우 간단한 코드 예제, 실행 결과, 헷갈리기 쉬운 점, 실제 참고한 출처를 포함한다. 확인하지 않은 실행 결과나 출처는 만들지 않는다.
- 같은 주제의 후속 질문은 기존 문서에 질문과 답변을 추가하고 수정일을 갱신한다. 기존 질문과 학습 흐름은 유지하되, 잘못된 설명은 바로잡고 정정 내용을 표시한다.
- 문서를 추가하거나 제목과 분류를 바꾸면 `glossary/README.md`의 질문 목록과 링크도 갱신한다. 분류는 AI, Python, Coding 중에서 선택하며 여러 개를 사용할 수 있다.
- 대화에서 실제로 확인할 수 있는 내용만 기록한다. 민감한 개인정보, 비밀번호, API 키는 저장하지 않는다. 파일 저장이 불가능하면 저장했다고 말하지 말고 사용자에게 알린다.
