## 질문

`bool`은 무엇인가요?

## 답변

`bool`은 참과 거짓을 나타내는 파이썬 자료형이며, 불리언(Boolean)이라고 부릅니다. 값은 `True`(참)와 `False`(거짓) 두 가지입니다. 재고 유무, 로그인 여부처럼 두 상태를 표현할 때 사용합니다.

현재 코드의 `in_stock: bool = True`에서 `in_stock`은 재고 여부를 뜻하는 필드 이름, `: bool`은 불리언 타입 표시, `= True`는 기본값입니다. 이 Book 모델에서는 재고 여부를 생략하면 `True`가 사용됩니다.

## 예제

```python
in_stock = True

if in_stock:
    print("재고가 있습니다.")
else:
    print("품절입니다.")
```

코드 설명: `in_stock`이 `True`이면 첫 번째 출력문을, `False`이면 두 번째 출력문을 실행합니다.

## 헷갈리기 쉬운 점

- `True`와 `False`는 첫 글자를 대문자로 씁니다.
- 따옴표가 있는 `"True"`, `"False"`는 불리언이 아니라 문자열입니다.
- 일반 파이썬에서 타입 힌트 자체가 값을 자동으로 검사하는 것은 아닙니다. 현재 코드의 Pydantic 모델은 필드 정보를 사용해 입력을 검증합니다.
