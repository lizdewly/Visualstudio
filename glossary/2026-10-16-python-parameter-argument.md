## 질문

parameter, argument?

## 답변

**parameter(매개변수)는 함수를 정의할 때 입력을 받도록 선언한 이름이고, argument(인자 또는 인수)는 함수를 호출할 때 전달하는 실제 값입니다.**

| 구분 | parameter | argument |
| --- | --- | --- |
| 한국어 | 매개변수 | 인자, 인수 |
| 등장하는 곳 | 함수 정의 | 함수 호출 |
| 예 | `def add(a, b):`의 `a`, `b` | `add(3, 5)`의 `3`, `5` |

## 예제

```python
def add(a, b):  # a, b는 매개변수
    return a + b

result = add(3, 5)  # 3, 5는 인자
print(result)       # 예상 결과: 8
```

호출하면 매개변수 `a`에 `3`, `b`에 `5`가 연결되고 함수 본문이 실행됩니다.

```python
x = 10
y = 20
print(add(x, y))  # 예상 결과: 30
```

인자는 숫자를 직접 적는 것뿐 아니라 변수나 계산식으로 전달할 수도 있습니다. 여기서는 `x`, `y`를 평가한 값인 `10`, `20`을 전달합니다. 함수의 매개변수 이름과 호출하는 쪽의 변수 이름은 같을 필요가 없습니다.

## 헷갈리기 쉬운 점

### 위치 인자와 키워드 인자

```python
add(3, 5)      # 위치 인자: 순서로 연결
add(b=5, a=3) # 키워드 인자: 매개변수 이름으로 연결
```

두 호출의 결과는 모두 `8`입니다. 키워드 인자로 전달할 때는 정의된 매개변수 이름을 사용합니다.

### 매개변수 기본값

```python
def greet(name="손님"):
    return f"안녕하세요, {name}"

print(greet())        # 예상 결과: 안녕하세요, 손님
print(greet("민수"))  # 예상 결과: 안녕하세요, 민수
```

`name`은 매개변수이고 `"손님"`은 기본값입니다. `greet()`는 인자 없이 호출해 기본값을 사용하고, `greet("민수")`는 전달한 인자를 사용합니다.

`return`으로 돌려주는 값은 반환값입니다. 함수에 전달하는 인자와 구분합니다.
