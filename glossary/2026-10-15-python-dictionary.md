파이썬 딕셔너리를 설명과 간단한 예제와 함께, 가장 많이 사용하는 케이스별로 정리해줘.

## 답변

**딕셔너리(`dict`)는 키(key)와 값(value)을 한 쌍으로 저장하는 자료형입니다.** 리스트가 주로 위치로 값을 찾는다면, 딕셔너리는 이름이나 번호 같은 키로 값을 찾습니다.

```python
student = {"name": "민수", "age": 20}
```

`"name"`은 키, `"민수"`는 그 키에 연결된 값입니다. 빈 딕셔너리는 `{}`로 만듭니다. 아래 사례는 사용 빈도의 정확한 순위가 아니라, 실습에서 자주 만나는 용도별 정리입니다. 코드의 결과 주석은 예상 결과이며 별도로 실행해 확인하지 않았습니다.

### 1. 한 대상의 정보 저장하기

이름, 나이, 점수처럼 한 대상의 여러 정보를 묶을 때 사용합니다.

```python
student = {"name": "민수", "age": 20, "score": 85}
print(student["name"])   # 민수
print(student["score"])  # 85
```

### 2. 없을 수도 있는 값 조회하기

`get(키, 기본값)`을 사용하면 키가 없을 때 기본값을 돌려줍니다.

```python
student = {"name": "민수"}
print(student.get("name"))          # 민수
print(student.get("score", 0))      # 0
print(student.get("email"))         # None
```

`student["score"]`처럼 없는 키를 대괄호로 조회하면 `KeyError`가 발생합니다. `get()`은 기본값을 반환해도 딕셔너리에 새 항목을 추가하지 않습니다. 기본값은 키가 없을 때만 사용하며, 기존 값이 `None`인 경우에는 그 값을 그대로 반환합니다.

### 3. 값 추가·수정·삭제하기

`딕셔너리[키] = 값`은 새 키이면 추가하고, 기존 키이면 값을 바꿉니다.

```python
student = {"name": "민수", "score": 85}
student["grade"] = "A"              # 추가
student["score"] = 95               # 수정
student.update({"age": 20, "score": 100})  # 여러 항목 추가·수정
del student["age"]                  # 삭제
grade = student.pop("grade", "미정") # 삭제하면서 값 반환
print(grade)                        # A
print(student)                      # {'name': '민수', 'score': 100}
```

없는 키에 `del`을 사용하면 오류가 납니다. `pop(키, 기본값)`은 키가 없으면 기본값을 반환합니다.

### 4. 전체 항목 반복하기

키와 값을 함께 사용할 때는 `items()`를 사용합니다.

```python
scores = {"국어": 90, "영어": 80}
for subject, score in scores.items():
    print(subject, score)
# 국어 90
# 영어 80
```

`for key in scores:`는 키를 순회하고, `scores.values()`는 값들을, `scores.keys()`는 키들을 제공합니다.

### 5. 코드나 이름을 다른 값으로 바꾸기

메뉴 번호, 상품 가격, 상태 코드처럼 대응 관계가 정해진 값을 찾을 때 사용합니다.

```python
status_names = {"ready": "준비", "running": "실행 중", "done": "완료"}
status = "running"
print(status_names.get(status, "알 수 없음"))  # 실행 중
print("done" in status_names)                # True
```

`in`은 기본적으로 키가 있는지 검사합니다. 값을 검사하려면 `"완료" in status_names.values()`처럼 씁니다.

### 6. 같은 항목이 몇 번 나오는지 세기

단어 수, 투표 수, 상품별 판매 건수 등을 집계할 때 사용합니다.

```python
fruits = ["사과", "바나나", "사과"]
counts = {}
for fruit in fruits:
    counts[fruit] = counts.get(fruit, 0) + 1
print(counts)  # {'사과': 2, '바나나': 1}
```

처음 나온 과일은 0에서 시작해 1을 더하고, 이미 나온 과일은 기존 개수에 1을 더합니다.

### 7. 같은 기준끼리 묶기

팀별 사람, 카테고리별 상품처럼 키 하나에 여러 값을 모을 때는 값으로 리스트를 저장합니다.

```python
members = [("A팀", "민수"), ("B팀", "지수"), ("A팀", "영희")]
teams = {}
for team, name in members:
    if team not in teams:
        teams[team] = []
    teams[team].append(name)
print(teams)  # {'A팀': ['민수', '영희'], 'B팀': ['지수']}
```

### 8. 여러 대상의 정보를 목록으로 관리하기

리스트 안에 딕셔너리를 넣으면 학생 명단이나 상품 목록을 표현할 수 있습니다.

```python
students = [
    {"name": "민수", "score": 85},
    {"name": "지수", "score": 95},
]
for student in students:
    if student["score"] >= 90:
        print(student["name"])  # 지수
```

`students[0]["name"]`은 첫 번째 학생의 이름입니다. `[0]`은 리스트의 위치, `["name"]`은 딕셔너리의 키를 뜻합니다.

## 헷갈리기 쉬운 점

- 같은 키를 여러 번 넣으면 마지막 값이 남습니다. `{"a": 1, "a": 2}`는 `{"a": 2}`가 됩니다. 서로 다른 키가 같은 값을 갖는 것은 가능합니다.
- 키에는 문자열이나 정수 등을 많이 사용합니다. 키는 해시 가능한 값이어야 하므로 리스트나 딕셔너리는 키로 사용할 수 없습니다. 값에는 리스트나 다른 딕셔너리도 넣을 수 있습니다.
- 딕셔너리는 삽입 순서를 유지하지만 키를 자동으로 정렬하지 않습니다. `d[0]`은 첫 항목이 아니라 정수 키 `0`에 연결된 값을 찾습니다.
- `b = a`는 딕셔너리를 복사하지 않고 같은 객체를 가리킵니다. `a.copy()`는 얕은 복사이므로 내부 리스트 같은 중첩 객체는 공유합니다.

처음에는 **`d[key]`, `d.get(key, 기본값)`, `d[key] = 값`, `d.items()`, `key in d`**부터 익히면 좋습니다.

## 후속 질문과 답변

### 2026년 10월 15일 dict와 list의 차이

질문: dict 과 list 의 차이?

**`list`는 위치(인덱스)로 값을 찾고, `dict`는 키로 값을 찾습니다.** 둘 다 여러 값을 저장하고 내용을 수정할 수 있지만, 저장 구조와 조회 방법이 다릅니다.

| 구분 | list 리스트 | dict 딕셔너리 |
| --- | --- | --- |
| 생성 문법 | `[값1, 값2]` | `{키1: 값1, 키2: 값2}` |
| 빈 자료구조 | `[]` | `{}` |
| 값 조회 | `items[0]`처럼 위치로 조회 | `user["name"]`처럼 키로 조회 |
| 순서 | 원소의 순서 유지 | 키의 삽입 순서 유지 |
| 중복 | 같은 값을 여러 위치에 저장 가능 | 키는 중복 불가, 값은 중복 가능 |
| 주로 쓰는 상황 | 점수 목록, 사용자 목록 | 한 사용자의 이름, 역할 등 항목별 정보 |

다음 코드의 주석은 예상 결과입니다.

```python
# list: 첫 번째, 두 번째처럼 위치로 구분
names = ["alpha", "bravo"]
print(names[0])  # alpha

# dict: 이름, 역할처럼 키로 구분
user = {"username": "alpha", "user_role": "admin"}
print(user["username"])  # alpha
```

이전에 사용한 `test_users`는 **리스트 안에 딕셔너리를 넣은 구조**입니다.

```python
test_users = [
    {"username": "alpha", "user_role": "admin"},
    {"username": "bravo", "user_role": "user"},
]

print(test_users[0]["user_role"])  # admin (예상 결과)
```

`test_users[0]`으로 첫 번째 사용자 딕셔너리를 고르고, `["user_role"]`로 그 사용자의 역할을 읽습니다.

주의할 점은 딕셔너리의 숫자 키도 위치가 아니라 키라는 것입니다. 예를 들어 `d = {10: "A", 0: "B"}`에서 `d[0]`은 첫 항목이 아닌 키 `0`의 값 `"B"`를 찾습니다.
