## 질문

`"/"`와 `"\"`의 차이는?

## 답변

`/`는 슬래시(slash), `\`는 역슬래시(backslash)이며 서로 다른 문자다. 사용 위치에 따라 역할이 달라진다.

| 사용 위치 | `/` | `\` |
| --- | --- | --- |
| URL | 경로 구분: `/users/1` | URL 경로 구분자로 사용하지 않음 |
| 파일 경로 | Linux·macOS의 경로 구분자 | Windows의 일반적인 경로 구분자 |
| 파이썬 코드 | 숫자 사이에서 나눗셈 연산자 | 일반 문자열에서 특수 문자 표현을 시작하는 기호 |

현재 `Day_7/main.py`의 `@app.get("/health")`에서 `/health`는 서버의 URL 경로다. 문자열 안의 `/`이므로 나눗셈이 아니다.

## 예제

```python
result = 10 / 2  # 나눗셈
text = "안녕\n파이썬"  # \n은 줄바꿈 문자
path = "C:\\study\\main.py"  # \\는 실제 역슬래시 하나
raw_path = r"C:\study\main.py"  # r을 붙여 역슬래시를 그대로 표현
```

예제는 설명용이며 실행하지 않았다.

## 헷갈리기 쉬운 점

- 일반 파이썬 문자열에서 역슬래시 하나를 표현하려면 `"\\"`라고 쓴다. `"\"`는 닫는 따옴표가 이스케이프되어 올바른 완성된 문자열이 아니다.
- `\n`은 줄바꿈, `\t`는 탭이므로 Windows 경로를 일반 문자열로 적을 때 주의한다.
- raw 문자열도 홀수 개의 역슬래시로 끝낼 수 없다.
- Windows에서도 파이썬의 많은 파일 경로 처리 함수는 `C:/study/main.py` 같은 슬래시 경로를 허용한다. 모든 명령줄 도구에 똑같이 적용되는 규칙은 아니다.
