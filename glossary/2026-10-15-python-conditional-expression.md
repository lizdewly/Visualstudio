# 파이썬 삼항 연산자 사용법

- 핵심 용어: 삼항 연산자, 조건부 표현식, if, else

## 질문

삼항연산자

## 답변

**삼항 연산자는 조건에 따라 두 값 중 하나를 선택하는 표현식입니다.** 파이썬에서는 보통 **조건부 표현식(conditional expression)**이라고 부릅니다. 조건과 두 값이라는 세 요소로 이루어져 있어 삼항 연산자라고도 합니다.

```python
참일_때_값 if 조건 else 거짓일_때_값
```

가운데의 조건을 먼저 확인합니다. 조건이 참이면 앞의 값을, 거짓이면 뒤의 값을 선택합니다. 선택된 쪽의 표현식만 평가합니다.

## 예제

### 나이에 따라 값 선택하기

이 예제에서는 나이가 19 이상인지에 따라 표시할 문자열을 선택합니다.

```python
age = 20
result = "성인" if age >= 19 else "미성년자"
print(result)
```

실제 실행 결과:

```text
성인
```

`age`를 `15`로 바꾸어 실행하면 `미성년자`가 출력됩니다. 두 경우 모두 실행해 확인했습니다.

위 코드는 다음 일반 조건문과 같은 결과를 만듭니다.

```python
age = 20

if age >= 19:
    result = "성인"
else:
    result = "미성년자"

print(result)
```

### 짝수와 홀수 구분하기

```python
number = 7
print("짝수" if number % 2 == 0 else "홀수")
```

실제 실행 결과:

```text
홀수
```

`%`는 나눗셈의 나머지를 구합니다. 정수를 2로 나눈 나머지가 0이면 짝수입니다.

## 헷갈리기 쉬운 점

- **파이썬은 `조건 ? 참일_때_값 : 거짓일_때_값` 문법을 사용하지 않습니다.** `참일_때_값 if 조건 else 거짓일_때_값` 순서로 씁니다.
- **조건부 표현식에는 `else`가 필요합니다.** 어느 경우든 선택할 값이 있어야 합니다.
- **한 줄로 값 하나를 선택할 때 사용하면 편리합니다.** 여러 동작을 수행하거나 조건이 복잡하면 일반 `if`/`else` 문으로 작성하는 편이 읽기 쉽습니다.
- **중첩할 수 있지만 처음에는 피하는 편이 좋습니다.** 조건부 표현식을 여러 개 연결하면 조건과 결과의 관계를 파악하기 어려워집니다.
