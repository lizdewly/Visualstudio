## 질문

`list_1 = ['a', 'b', 'c']`, `list_2 = [100, 200, 300]`으로 `result = zip(list_1, list_2)`를 만들었다. `for i in result: print(i)`로 출력한 뒤 `results2 = dict(result)`를 실행한다. zip으로 생성한 객체를 dict로 변환하려면 어떻게 하는가?

## 답변

`dict(zip(list_1, list_2))`로 변환한다. 첫 번째 리스트의 원소가 키, 두 번째 리스트의 원소가 값이 된다.

사용자가 작성한 `dict(result)`도 올바른 변환 문법이다. 다만 앞의 for 문이 zip 객체의 원소를 모두 꺼내 사용했기 때문에 남아 있는 원소가 없어 빈 딕셔너리 `{}`가 된다. zip 객체는 순서대로 원소를 꺼내는 이터레이터이며, 소진된 뒤에는 처음으로 자동 이동하지 않는다.

## 예제

### 바로 딕셔너리로 변환하기

```python
list_1 = ['a', 'b', 'c']
list_2 = [100, 200, 300]
results2 = dict(zip(list_1, list_2))
print(results2)
```

실제 변환 실행으로 확인한 출력:

```text
{'a': 100, 'b': 200, 'c': 300}
```

이미 for 문으로 result를 사용했다면 위 코드처럼 zip 객체를 새로 만들어 변환하면 된다.

### 반복 출력과 딕셔너리 변환을 둘 다 하기

```python
list_1 = ['a', 'b', 'c']
list_2 = [100, 200, 300]
result = list(zip(list_1, list_2))

for i in result:
    print(i)

results2 = dict(result)
print(results2)
```

먼저 리스트에 쌍을 저장하면 여러 번 순회할 수 있다. `list(zip(...))`의 실제 내용이 `[('a', 100), ('b', 200), ('c', 300)]`임을 확인했고, 저장한 리스트를 두 번 dict로 변환해도 두 결과 모두 `{'a': 100, 'b': 200, 'c': 300}`임을 확인했다. zip 객체를 `list(result)`로 소진한 뒤 `dict(result)`를 호출하면 `{}`가 되는 것도 실행해 확인했다.

## 헷갈리기 쉬운 점

- `print(range(5))`는 별개 코드로 zip 객체를 소진시키지 않는다.
- `dict(result)`도 이터레이터의 원소를 사용한다. 소진 후 재사용하려면 새 zip 객체를 만들거나 미리 리스트로 저장한다.
- 키가 중복되면 마지막 값이 남는다. 기본 zip은 두 리스트 중 짧은 쪽 길이까지만 쌍을 만든다.
