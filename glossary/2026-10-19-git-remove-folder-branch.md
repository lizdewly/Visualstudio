## 질문

Git에서 브랜치 폴더를 어떻게 삭제하나요?

## 답변

Git에는 “브랜치 폴더”라는 하나의 항목이 따로 있지 않습니다. 폴더를 저장소에서 지우려는 것인지, 브랜치를 지우려는 것인지에 따라 명령이 다릅니다. 아래 경로와 브랜치 이름은 실제 값으로 바꿉니다.

## 저장소에서 폴더 삭제

현재 브랜치에서 폴더를 지우고 변경 사항을 원격 저장소에도 반영하려면 해당 브랜치에서 다음 명령을 실행합니다.

```powershell
git rm -r -- "폴더경로"
git commit -m "Remove folder"
git push origin 브랜치이름
```

예를 들어 `Day_4` 폴더를 현재 브랜치에서 제거하려면 `git rm -r -- "Day_4"`처럼 경로를 지정합니다. `git rm`은 추적 중인 파일을 작업 폴더에서 삭제하고 삭제 내용을 스테이징합니다. 커밋과 push까지 해야 다른 사람과 원격 저장소에도 삭제가 반영됩니다.

Git에서는 제거하되 내 컴퓨터에는 파일을 남기고 싶다면 `git rm -r --cached -- "폴더경로"`를 사용하고, 해당 폴더 경로를 `.gitignore`에도 추가한 뒤 커밋하고 push합니다.

## 브랜치 삭제

현재 사용 중인 브랜치는 삭제할 수 없으므로 먼저 다른 브랜치로 이동합니다. 예를 들어 `feature` 브랜치를 로컬과 원격에서 각각 삭제하는 안내용 명령은 다음과 같습니다.

```powershell
git switch main
git branch -d feature
git push origin --delete feature
```

로컬의 `git branch -d`는 병합되지 않은 변경이 있으면 삭제를 막습니다. `-D`는 그 보호를 무시하므로, 작업을 잃을 수 있어 확실히 필요할 때만 사용합니다. 원격 브랜치 삭제 명령은 원격 저장소에서 해당 브랜치를 지웁니다.

## 헷갈리기 쉬운 점

- 폴더 삭제는 현재 브랜치의 파일을 바꾸는 것이고, 브랜치 삭제는 그 브랜치 이름과 참조를 지우는 것입니다.
- Git은 파일을 추적하며, 빈 폴더 자체는 추적하지 않습니다. 폴더의 파일을 모두 삭제하면 빈 폴더도 저장소에 남지 않습니다.
- 특정 브랜치에서 폴더를 없애도 다른 브랜치에는 그 폴더가 남아 있을 수 있습니다.
- 명령 예시는 설명용이며 실행하지 않았습니다. 삭제 전에 `git status`로 현재 브랜치와 변경 내용을 확인합니다.
