## 질문

`" "`와 `' '`의 차이는?

## 답변

파이썬에서 큰따옴표와 작은따옴표는 모두 문자열을 만드는 기호이며 기능 차이가 없다. `"안녕"`과 `'안녕'`은 같은 문자열 값이다. `" "`와 `' '`도 모두 공백 한 칸을 담은 문자열이다.

문자열 내용에 따옴표가 들어갈 때 바깥쪽을 다른 종류로 감싸면 편하다. 프로젝트에서 정한 스타일이 있다면 그 스타일을 따른다.

## 예제

```python
a = "안녕"
b = '안녕'

message = "I'm learning Python."  # 내용에 작은따옴표 포함
quote = '그가 "안녕"이라고 말했다.'  # 내용에 큰따옴표 포함
escaped = 'I\'m learning Python.'  # 같은 종류라면 역슬래시로 처리
```

위 코드는 설명용이며 실행하지 않았다. `a`와 `b`는 같은 값이고, `message`와 `escaped`도 같은 값이다.

## 헷갈리기 쉬운 점

- 시작과 끝은 같은 종류의 따옴표여야 한다. `"안녕'`은 문법 오류다.
- 작은따옴표로 감싼 한 글자도 파이썬에서는 문자열(`str`)이다.
- `""`는 빈 문자열이고, `" "`는 공백 한 칸이 들어 있는 문자열이다.
- 두 종류 모두 `\n` 같은 이스케이프를 처리한다.
- JSON 문법에서는 문자열에 큰따옴표를 사용해야 한다. 파이썬 문자열 문법과 구별한다.
