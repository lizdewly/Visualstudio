## 질문

`.venv`가 뭐야?

## 답변

`.venv`는 보통 프로젝트에서 사용하는 **파이썬 가상 환경을 담는 폴더 이름**이다. 가상 환경은 프로젝트별로 파이썬 실행 환경과 설치한 외부 패키지를 따로 관리하는 공간이다.

예를 들어 프로젝트 A에는 어떤 패키지의 1버전이, 프로젝트 B에는 2버전이 필요할 수 있다. 각각 가상 환경을 사용하면 서로 다른 버전을 관리하기 쉽다. 운영체제 전체를 가상으로 실행하는 것은 아니다.

## 예제

Windows PowerShell에서 프로젝트 폴더를 연 뒤 사용하는 명령 예시다. 이 답변에서는 명령을 실행하거나 가상 환경을 생성하지 않았다.

```powershell
# 가상 환경을 .venv 폴더에 만들기
py -m venv .venv

# 현재 터미널에서 가상 환경 활성화하기
.\.venv\Scripts\Activate.ps1

# 활성화한 환경에 외부 패키지 설치하기
python -m pip install requests

# 활성화 종료하기
deactivate
```

## 헷갈리기 쉬운 점

- `venv`는 파이썬에 포함된 가상 환경 생성 모듈이고, `.venv`는 관례적인 폴더 이름이다. 다른 이름으로 만들 수도 있다.
- 활성화는 현재 터미널에서 해당 환경의 파이썬을 쉽게 사용하도록 경로를 설정하는 과정이다. 활성화 없이 `.\.venv\Scripts\python.exe`를 직접 실행할 수도 있다.
- `.venv`는 직접 작성한 파이썬 코드 파일이 아니다. 보통 Git에 올리지 않고 `.gitignore`에 `.venv/`를 적어 제외한다.
- PowerShell 설정에 따라 활성화 스크립트 실행이 차단될 수 있다. 이때는 해당 환경의 파이썬 실행 파일을 직접 사용할 수 있다.
