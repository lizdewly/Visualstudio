## 질문

파이썬에서 "@"의 활용

## 답변

**`@`는 주로 데코레이터를 적용하거나 행렬 곱셈을 표현할 때 사용합니다.** 어디에 쓰였는지에 따라 의미가 달라집니다.

| 형태 | 의미 | 용도 |
| --- | --- | --- |
| 함수나 클래스 정의 바로 위의 `@이름` | 데코레이터 적용 | 기능 추가, 등록, 동작 변경 등 |
| 두 값 사이의 `A @ B` | 행렬 곱셈 연산자 | 행렬 계산을 지원하는 객체의 곱셈 |

## 예제

### 함수에 데코레이터 적용하기

데코레이터는 함수나 클래스를 받아 처리한 뒤, 그 결과를 반환하는 호출 가능한 객체입니다. 다음은 원래 함수의 실행 전후에 메시지를 출력하도록 감싸는 간단한 함수 데코레이터입니다.

```python
def announce(func):
    def wrapper():
        print("함수 실행 전")
        func()
        print("함수 실행 후")
    return wrapper

@announce
def hello():
    print("안녕하세요")

hello()
```

실제 실행 결과:

```text
함수 실행 전
안녕하세요
함수 실행 후
```

`announce`의 매개변수 `func`에는 원래 `hello` 함수가 전달됩니다. `announce`는 새 함수 `wrapper`를 반환하며, 이후 `hello()`를 호출하면 이 `wrapper`가 실행됩니다. `wrapper` 안의 `func()`가 원래 함수를 실행합니다.

위의 `@announce` 적용은 다음 형태로 이해할 수 있습니다.

```python
def hello():
    print("안녕하세요")

hello = announce(hello)
```

이 예제는 인자를 받지 않고 반환값도 없는 `hello()`에 맞춘 형태입니다. 인자와 반환값을 가진 일반 함수를 감쌀 때는 전달과 반환 처리를 추가합니다.

### 자주 보이는 데코레이터

| 표현 | 용도 |
| --- | --- |
| `@property` | 메서드로 계산하는 값을 속성처럼 읽도록 정의 |
| `@staticmethod` | 인스턴스나 클래스를 자동으로 첫 인자로 받지 않는 메서드 정의 |
| `@classmethod` | 클래스를 자동으로 첫 인자로 받는 메서드 정의 |

API 프레임워크에서도 데코레이터로 URL과 함수를 연결하는 경우가 있습니다. 데코레이터는 실행 전후에 기능을 추가하는 것 외에 함수를 등록하는 데에도 사용됩니다.

### 행렬 곱셈

`A @ B`는 행렬 곱셈 연산을 표현합니다. 일반적인 행렬 곱셈은 왼쪽 행렬의 행과 오른쪽 행렬의 열을 조합해 계산하며, 원소별 곱셈과 다릅니다.

이 연산은 해당 동작을 지원하는 객체에서 사용할 수 있습니다. **일반 파이썬 리스트나 숫자는 `@`를 지원하지 않습니다.** 예를 들어 `[[1, 2]] @ [[3], [4]]`는 `TypeError`를 발생시킵니다. 행렬 곱셈을 지원하는 타입에서는 `__matmul__` 같은 특수 메서드로 연산을 구현합니다.

## 헷갈리기 쉬운 점

- `@announce`는 주석이 아닙니다. 주석은 `#`으로 시작합니다.
- 데코레이터는 함수 정의가 실행될 때 적용됩니다. 위 예제에서 적용 시점에는 `wrapper`를 반환하고, 메시지 출력은 나중에 `hello()`를 호출할 때 일어납니다.
- 여러 데코레이터를 쌓으면 아래쪽부터 적용합니다. `@outer` 아래에 `@inner`가 있으면 `func = outer(inner(func))` 형태입니다.
- 문자열 안의 `"user@example.com"`에서 `@`는 일반 문자입니다.
- `@`가 항상 권한 검사나 로그 출력을 의미하지는 않습니다. 어떤 데코레이터를 붙였는지에 따라 동작이 달라집니다.
