## 질문

CMD와 PowerShell을 쓸 때 차이는?

## 답변

둘 다 명령어를 입력해 프로그램을 실행하거나 파일을 관리하는 셸이다. CMD(명령 프롬프트)는 전통적인 Windows 명령과 배치 파일을 실행하는 데 쓰이고, PowerShell은 객체를 다루는 명령과 스크립트로 복잡한 관리·자동화 작업을 할 수 있다.

CMD의 파이프는 주로 텍스트를 전달한다. PowerShell의 기본 명령인 cmdlet 사이에서는 파일 이름, 크기 등의 속성이 있는 객체를 전달하므로 조건에 맞는 자료를 골라내기 편하다. 외부 프로그램을 연결할 때까지 항상 객체가 전달되는 것은 아니다.

파이썬 파일을 실행하는 `py day2.py`와 같은 명령은 두 셸에서 동일하게 사용할 수 있다. 차이는 주로 환경 변수, 가상 환경 활성화, 여러 명령을 연결하는 문법에서 나타난다. 처음에는 하나를 골라 익히되, 따라 하는 예제가 어느 셸 기준인지 확인하면 좋다.

## 헷갈리기 쉬운 점

- Windows Terminal이나 VS Code 터미널은 셸을 담는 화면이다. 그 안에서 CMD 또는 PowerShell을 사용할 수 있다.
- PowerShell의 `dir`은 보통 `Get-ChildItem`의 별칭이다. 이름이 같아도 CMD의 `dir`과 옵션 및 동작이 완전히 같지는 않다.
- PowerShell에서는 현재 폴더의 실행 파일이나 스크립트를 실행할 때 `./` 또는 Windows에서 흔히 쓰는 `.\` 접두사가 필요할 수 있다. `py`처럼 PATH에 등록된 명령에는 붙이지 않는다.
- PowerShell의 가상 환경 활성화는 실행 정책에 따라 차단될 수 있다. 활성화 없이 `.\.venv\Scripts\python.exe day2.py`로 해당 환경의 파이썬을 직접 실행할 수도 있다.
