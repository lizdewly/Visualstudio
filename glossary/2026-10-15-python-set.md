## 답변

**`set`은 중복된 원소를 저장하지 않는 집합 자료형입니다.** 원소의 순서나 위치를 보장하지 않으므로 인덱스로 조회할 수 없습니다. 중복 제거, 포함 여부 검사, 집합 연산에 사용합니다.

```python
numbers = {1, 2, 3}
empty_set = set()  # 빈 집합
```

`{}`는 빈 딕셔너리이므로 빈 집합은 반드시 `set()`으로 만듭니다.

## 예제

아래 결과는 실제 실행해 확인했습니다. 집합의 출력 순서에 의존하지 않도록 `sorted()`로 정렬한 리스트를 출력합니다.

### 중복 제거

```python
numbers = [3, 1, 3, 2]
unique_numbers = set(numbers)
print(sorted(unique_numbers))  # [1, 2, 3]
```

원래 리스트는 바꾸지 않습니다. `set()`으로 바꾸면 원래 순서는 보존되지 않습니다.

### 집합 연산

```python
a = {1, 2, 3}
b = {3, 4}

print(sorted(a | b))  # 합집합: [1, 2, 3, 4]
print(sorted(a & b))  # 교집합: [3]
print(sorted(a - b))  # 차집합: [1, 2]
```

합집합은 양쪽의 모든 원소, 교집합은 공통 원소, `a - b`는 a에만 있는 원소를 구합니다.

## 헷갈리기 쉬운 점

- `값 in 집합`으로 포함 여부를 확인합니다.
- `집합.add(값)`은 원소 하나를 추가합니다. 이미 있는 값이면 중복으로 추가하지 않습니다.
- `집합.remove(값)`는 원소를 삭제하지만 없으면 `KeyError`가 발생합니다. `집합.discard(값)`는 없어도 오류가 나지 않습니다.
- 집합에는 정수나 문자열처럼 해시 가능한 값을 넣습니다. 리스트나 딕셔너리를 그대로 원소로 넣을 수는 없습니다.
- `집합[0]`처럼 위치로 조회할 수 없습니다. 위치와 중복이 필요한 목록이라면 `list`를 사용합니다.
