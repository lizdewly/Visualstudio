## 질문

array, fload

`fload`는 문맥상 `float`의 오타로 보고 설명합니다.

## 답변

**array(배열)는 여러 값을 순서대로 저장하고 위치 번호로 접근하는 자료구조입니다.** 예를 들어 여러 학생의 점수를 모아 저장할 때 사용할 수 있습니다. 배열의 구체적인 규칙은 언어나 구현에 따라 다릅니다.

파이썬 기초에서 `scores = [80, 90, 100]`처럼 대괄호로 만드는 것은 정확히는 **리스트(`list`)**입니다. 여러 값을 순서대로 다룰 때 흔히 사용하지만, `array`와 같은 자료형은 아닙니다. 파이썬 표준 라이브러리에는 같은 타입의 기본 값들을 저장하는 `array.array`도 있습니다.

**float는 `3.14`, `175.5`처럼 소수가 있는 수를 표현할 때 사용하는 부동소수점 자료형입니다.** 정수를 표현하는 `int`와 구분합니다. 모든 실수를 정확하게 저장하는 것은 아니고, 표현 가능한 정밀도에 한계가 있습니다.

| 용어 | 역할 | 예 |
| --- | --- | --- |
| array | 여러 값을 모아 다루는 자료구조 | 여러 점수의 배열 |
| list | 파이썬에서 여러 값을 순서대로 저장하는 자료형 | `[80, 90, 100]` |
| int | 정수 자료형 | `10` |
| float | 부동소수점 수 자료형 | `10.0`, `3.14` |

배열이나 리스트의 원소로 `float` 값을 저장할 수도 있습니다. 예를 들어 `[1.5, 2.5, 3.5]`는 세 개의 `float` 객체를 담은 리스트입니다.

## 예제

### 리스트에서 값 가져오기

```python
scores = [80, 90, 100]
print(scores[0])
```

실제 실행 결과:

```text
80
```

인덱스는 0부터 시작하므로 `scores[0]`이 첫 번째 값입니다.

### float 값과 형 변환

```python
height = 175.5
print(type(height))
print(float("3.14"))  # 숫자 모양의 문자열을 float로 변환
print(float(3))       # 정수를 float로 변환
```

실제 실행 결과:

```text
<class 'float'>
3.14
3.0
```

## 헷갈리기 쉬운 점

- 파이썬의 올바른 이름은 `float`입니다. `fload`는 파이썬의 기본 자료형 이름이 아닙니다.
- `[1, 2, 3]`의 자료형 이름은 `list`입니다. 리스트는 서로 다른 타입의 객체도 담을 수 있습니다.
- `float("3.14")`는 가능하지만 `float("hello")`처럼 숫자로 해석할 수 없는 문자열은 `ValueError`를 발생시킵니다.
- `input()`은 문자열을 반환합니다. 소수 입력을 계산에 사용하려면 `height = float(input("키: "))`처럼 변환합니다.
- `float`는 일부 소수를 근삿값으로 저장합니다. `print(0.1 + 0.2)`를 실제 실행하면 `0.30000000000000004`가 출력됩니다. 이는 부동소수점 표현의 정밀도 한계 때문입니다.

## 후속 질문과 답변

### 2026년 10월 15일 기본 자료형 구분 문제

질문: 다음 중 파이썬의 기본자료형이 아닌 것은 무엇이야? 1) int, 2) str, 3) array, 4) float

**정답은 3번 `array`입니다.** 이 문제의 기본 자료형은 별도의 import 없이 사용할 수 있는 내장 자료형을 뜻합니다.

| 보기 | 의미 | 내장 자료형 여부 |
| --- | --- | --- |
| `int` | 정수: `10` | 해당 |
| `str` | 문자열: `"hello"` | 해당 |
| `array` | 배열 | 해당하지 않음 |
| `float` | 부동소수점 수: `3.14` | 해당 |

파이썬에도 배열은 있습니다. 다만 `array.array`는 표준 라이브러리의 `array` 모듈에서 가져와 사용하는 타입입니다. 내장 자료형인 `list`와 구분합니다.
