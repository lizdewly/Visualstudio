## 질문

다음 중 변수 이름으로 사용할 수 없는 것은?

1. `my_var`
2. `_name`
3. `2ndValue`
4. `value2`

## 답변

**정답은 3번 `2ndValue`입니다. 변수 이름은 숫자로 시작할 수 없습니다.** 숫자는 첫 글자 뒤에는 사용할 수 있습니다.

| 보기 | 사용 가능 여부 | 이유 |
| --- | --- | --- |
| `my_var` | 가능 | 문자로 시작하고 밑줄을 포함함 |
| `_name` | 가능 | 밑줄로 시작할 수 있음 |
| `2ndValue` | 불가능 | 숫자로 시작함 |
| `value2` | 가능 | 문자로 시작하며 숫자가 뒤에 있음 |

## 예제

```python
my_var = 10
_name = "민수"
value2 = 20
second_value = 30  # 2ndValue 대신 사용할 수 있는 이름
```

## 헷갈리기 쉬운 점

- 영어 기준으로는 문자 또는 밑줄(`_`)로 시작하고, 그 뒤에 문자·숫자·밑줄을 사용할 수 있습니다. 파이썬은 한글 등 일부 유니코드 문자도 식별자로 허용합니다.
- 공백과 하이픈(`-`)은 변수 이름에 사용할 수 없습니다. 단어 구분에는 `my_var`처럼 밑줄을 사용합니다.
- `if`, `for`, `class` 같은 예약어는 변수 이름으로 사용할 수 없습니다.
- 대소문자를 구분하므로 `value`와 `Value`는 서로 다른 이름입니다.
- `_name`도 유효한 변수 이름입니다. 앞의 밑줄은 보통 내부 용도임을 나타내는 관례이며, 변수로 사용할 수 없다는 뜻이 아닙니다.
