# 파이썬에서 객체란 무엇인가

- 최초 기록일: 2026-10-15
- 수정일: 2026-10-15
- 분류: Python, Coding
- 핵심 용어: 객체, 변수, 타입, 클래스, 메서드, 참조

## 질문

객체에 대한 설명도 넣어줘.

## 답변

**객체(object)는 프로그램에서 다루는 값의 실체입니다.** 파이썬에서는 숫자, 문자열, 리스트뿐 아니라 함수와 클래스도 객체입니다. 객체를 직접 클래스로 만들어야만 사용하는 것은 아닙니다. `10`이나 `"안녕"`을 쓰는 순간에도 객체를 다루고 있습니다.

객체를 이해할 때는 다음 세 가지를 생각하면 됩니다.

| 개념 | 뜻 | `[1, 2, 3]`의 예 |
| --- | --- | --- |
| 타입(type) | 어떤 종류이며 어떤 연산을 지원하는가 | 리스트인 `list` |
| 값(value) | 어떤 내용을 가지고 있는가 | 원소 `1`, `2`, `3` |
| 정체성(identity) | 다른 객체와 구별되는 그 객체 자체 | 내용이 같은 별개의 리스트와도 구별됨 |

**변수는 객체를 가리키는 이름입니다.** `numbers = [1, 2, 3]`에서 `numbers`는 변수 이름이고, `[1, 2, 3]`은 그 이름이 가리키는 리스트 객체입니다. 같은 객체에 여러 이름을 붙일 수도 있습니다.

객체와 연결된 데이터에는 **속성(attribute)**으로 접근할 수 있고, 객체와 연결된 함수를 **메서드(method)**라고 부릅니다. 예를 들어 `numbers.append(4)`는 리스트 객체에 원소를 추가하는 메서드를 호출합니다. 속성은 보통 `객체.이름`, 메서드 호출은 `객체.이름(...)` 형태로 씁니다.

**클래스(class)는 객체의 종류와 동작을 정의합니다.** 클래스를 설계도에, 그 클래스의 인스턴스(instance)를 설계도로 만든 개별 물건에 비유할 수 있습니다. `[1, 2, 3]`은 `list` 클래스의 인스턴스입니다. 객체라는 말은 넓은 표현이고, 인스턴스라는 말은 어떤 클래스에 속하는지를 강조할 때 사용합니다.

## 예제

### 두 변수가 같은 리스트 객체를 가리키는 경우

```python
numbers = [1, 2, 3]
same_numbers = numbers  # 리스트를 복사하지 않고 같은 객체를 가리킴

numbers.append(4)

print(type(numbers))
print(numbers)
print(same_numbers)
print(numbers is same_numbers)  # 같은 객체인지 확인
```

실제 실행 결과:

```text
<class 'list'>
[1, 2, 3, 4]
[1, 2, 3, 4]
True
```

두 이름이 같은 리스트를 가리키기 때문에 `numbers`를 통해 리스트를 바꾸면 `same_numbers`로 확인해도 바뀐 내용이 보입니다.

### 문자열 메서드를 사용하는 경우

```python
name = "python"
print(name.upper())  # 대문자로 된 문자열을 반환
print(name)
```

실제 실행 결과:

```text
PYTHON
python
```

문자열은 내용을 직접 바꿀 수 없는 객체입니다. `upper()`는 원래 문자열을 수정하지 않고 대문자로 된 문자열을 반환하므로, `name`은 여전히 `"python"`을 가리킵니다.

## 헷갈리기 쉬운 점

- **변수와 객체는 다릅니다.** 변수는 이름이고, 객체는 그 이름이 가리키는 실체입니다.
- **대입은 복사를 뜻하지 않습니다.** `b = a`는 `a`가 가리키는 객체에 `b`라는 이름도 연결합니다.
- **메서드가 항상 원본을 바꾸는 것은 아닙니다.** 리스트의 `append()`는 원본을 바꾸지만, 문자열의 `upper()`는 원본을 바꾸지 않습니다.
- **`==`와 `is`는 목적이 다릅니다.** `==`는 값이 같은지 비교할 때, `is`는 동일한 객체인지 확인할 때 사용합니다. 숫자나 문자열의 값 비교에는 보통 `==`를 사용합니다.
