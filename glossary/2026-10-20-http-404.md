## 질문

"404 not found" meaning? (404 Not Found는 무슨 뜻인가요?)

## 답변

`404 Not Found`는 **요청한 주소에 해당하는 페이지나 파일을 서버에서 찾을 수 없다**는 뜻의 HTTP 상태 코드다. `Not Found`는 한국어로 “찾을 수 없음”이라는 뜻이다.

흔한 원인은 다음과 같다.

- 주소(URL)에 오타가 있다.
- 페이지나 파일이 삭제되거나 다른 주소로 옮겨졌다.
- 개발 중인 웹사이트에서 해당 주소를 처리하는 경로가 설정되지 않았다.

먼저 주소를 확인하고, 사이트의 첫 화면이나 검색 기능에서 원하는 페이지를 다시 찾을 수 있다.

## 예제

가상의 사이트에서 `/about` 페이지는 있지만 `/abot` 페이지는 없다고 가정하자. 주소를 `/abot`으로 잘못 입력하면 서버가 `404 Not Found`를 응답할 수 있다. 실제 사이트에서 실행해 확인한 결과가 아닌 설명용 예시다.

## 헷갈리기 쉬운 점

- 404 응답을 받았다는 것은 서버가 HTTP 응답을 보냈다는 뜻이다. 인터넷 연결 자체가 끊겼다는 뜻은 아니다.
- 404만으로 페이지가 영구적으로 삭제되었다고 확정할 수는 없다.
- 일부 서비스는 접근 권한이 없는 자원의 존재를 숨기기 위해 404를 반환하기도 한다.
