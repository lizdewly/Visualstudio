## 답변

따옴표 바로 앞에 붙는 f는 formatted string literal을 만드는 접두사다. 문자열의 중괄호 안에 변수나 계산식을 넣으면 그 값을 문자열에 채운다. 출력 전용 기능이 아니라 문자열을 만드는 문법이다.

현재 코드의 `client.get(f'/item/{item_id}')`는 item_id 값을 경로에 넣는다. item_id가 3이면 요청 경로 문자열은 `/item/3`이다. f가 없으면 `/item/{item_id}`라는 글자 그대로다.

## 예제

아래 주석은 코드상 예상값이며 이번 답변에서 실행하지 않았다.

```python
name = "민수"
item_id = 3
price = 12000
elapsed = 1.23456

message = f"안녕하세요, {name}님"  # 안녕하세요, 민수님
path = f"/item/{item_id}"          # /item/3
total = f"합계: {price * 2}원"     # 합계: 24000원
formatted = f"{price:,}원"         # 12,000원
duration = f"{elapsed:.2f}초"      # 1.23초
braces = f"번호: {{{item_id}}}"    # 번호: {3}
```

## 헷갈리기 쉬운 점

- 작은따옴표와 큰따옴표 모두 가능하다: `f'...'`, `f"..."`.
- f는 따옴표 바깥 앞에 붙인다. `"f..."`는 문자열 내용에 f를 넣는 것이다.
- 중괄호 안의 변수는 미리 정의되어 있어야 한다.
- 문자열 자체에 중괄호를 넣으려면 `{{`, `}}`로 적는다.
- `f"{elapsed:.2f}"`의 앞 f는 f-string 접두사이고, `:.2f`의 f는 고정소수점 표시 형식이다. `.2`는 소수점 이하 두 자리 표시를 뜻한다.
- 숫자를 f-string에 넣으면 결과는 문자열이다. `round(elapsed, 2)`처럼 숫자를 반환하는 연산과 구별한다.
- FastAPI의 `@app.get('/item/{item_id}')`는 프레임워크가 해석하는 경로 매개변수 선언이므로 보통 f를 붙이지 않는다. 요청을 보낼 실제 URL을 만드는 `f'/item/{item_id}'`와 역할이 다르다.

## 후속 질문과 답변

### 2026-10-22: round란? f와의 차이는?

round(숫자, 자릿수)는 지정한 자리로 반올림한 숫자를 반환한다. f-string은 값을 넣어 문자열을 만든다. 특히 f"{값:.2f}"는 소수점 이하 두 자리로 표시하는 문자열을 만든다. 두 방법 모두 원래 변수를 직접 변경하지 않는다.

실제 `py -c`로 확인한 결과:

```python
x = 1.2
a = round(x, 2)  # 1.2, float
b = f"{x:.2f}"  # '1.20', str
round(1.23456, 2)  # 1.23
round(2.5)        # 2
round(3.5)        # 4
round(2.675, 2)   # 2.67
```

- 계산할 숫자가 필요하면 round를 사용한다.
- 소수점 자릿수를 맞춰 화면에 표시하려면 f-string의 서식을 사용한다.
- round는 뒤에 0을 붙여 표시 자릿수를 고정하지 않는다.
- 일반 int/float에서 자릿수를 생략한 round(x)는 정수를 반환한다.
- Python의 round는 정확히 중간인 경우 가까운 짝수 쪽을 선택한다. 무조건 5에서 올리는 규칙과 다르다.
- float는 일부 소수를 정확히 저장하지 못하므로 2.675 같은 값에서 예상과 다른 반올림이 나타날 수 있다.
- 현재 코드의 round(perf_counter() - start, 3)는 경과 시간을 소수점 이하 세 자리로 반올림한 숫자로 반환하기 위한 것이다. f"{elapsed:.3f}"를 쓰면 세 자리로 표시되는 문자열이 된다.
