## 질문

if not prompt.strip() 무슨뜻?

## 답변

**`prompt`가 문자열일 때, 빈 문자열이거나 공백 문자만 있는지 확인하는 조건입니다.**

```python
if not prompt.strip():
    print("내용을 입력해 주세요")
```

1. `prompt.strip()`은 양 끝의 공백 문자를 제거한 문자열을 반환합니다. 기본적으로 스페이스, 탭, 줄바꿈 등을 제거합니다.
2. 파이썬의 조건식에서 빈 문자열 `""`은 거짓으로, 내용이 있는 문자열은 참으로 판단합니다.
3. `not`은 참과 거짓을 뒤집습니다. 따라서 공백 제거 결과가 비어 있으면 `not`의 결과는 `True`가 되어 조건문 안을 실행합니다.

## 예제

다음 결과는 실제 실행해 확인했습니다.

| prompt | prompt.strip() | not prompt.strip() |
| --- | --- | --- |
| `""` | `""` | `True` |
| `"   "` | `""` | `True` |
| `"  hello  "` | `"hello"` | `False` |
| `"\t\n"` | `""` | `True` |

입력 확인 예제:

```python
prompt = input("질문을 입력하세요: ")

if not prompt.strip():
    print("내용을 입력해 주세요")
else:
    print("입력한 질문:", prompt.strip())
```

## 헷갈리기 쉬운 점

- `strip()`은 문자열 중간의 공백은 제거하지 않습니다. `"hello world"`의 단어 사이 공백은 그대로입니다.
- `strip()`은 원본 문자열을 수정하지 않습니다. 결과를 계속 사용하려면 `prompt = prompt.strip()`처럼 다시 대입합니다.
- `if not prompt:`는 빈 문자열만 걸러내지만, `if not prompt.strip():`는 스페이스나 탭 등 공백 문자만 입력한 경우도 걸러냅니다.
- 이 설명은 `prompt`가 문자열이라는 전제입니다. `None`에는 `strip()`이 없어 `AttributeError`가 발생합니다.
