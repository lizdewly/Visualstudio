## 답변

**`.pop()`은 원본에서 항목을 제거하면서 그 값을 반환하는 메서드입니다.** 반환한다는 것은 꺼낸 값을 변수에 저장하거나 다른 계산에 사용할 수 있도록 돌려준다는 뜻입니다.

앞의 점 `.`은 객체의 메서드에 접근한다는 뜻이고, 뒤의 괄호 `()`는 그 메서드를 호출한다는 뜻입니다. `pop`의 사용법은 앞에 오는 객체의 종류에 따라 달라집니다.

| 대상 | 사용법 | 동작 |
| --- | --- | --- |
| 리스트 | `리스트.pop()` | 마지막 항목을 제거하고 반환 |
| 리스트 | `리스트.pop(인덱스)` | 지정한 위치의 항목을 제거하고 반환 |
| 딕셔너리 | `딕셔너리.pop(키)` | 지정한 키의 항목을 제거하고 그 값을 반환 |
| 딕셔너리 | `딕셔너리.pop(키, 기본값)` | 키가 있으면 제거하고 값을 반환하며, 없으면 기본값 반환 |

## 예제

### 리스트에서 값 꺼내기

```python
items = [10, 20, 30]

value = items.pop()  # 마지막 값인 30을 꺼냄
print(value)
print(items)

value = items.pop(0)  # 0번 위치의 값인 10을 꺼냄
print(value)
print(items)
```

실제 실행 결과:

```text
30
[10, 20]
10
[20]
```

리스트의 위치 번호인 인덱스는 0부터 시작합니다. `pop(0)`의 `0`은 삭제할 값이 아니라 위치입니다. 항목을 제거하면 뒤에 있던 항목들의 위치가 앞으로 당겨집니다.

### 딕셔너리에서 값 꺼내기

```python
person = {"name": "Min", "age": 20}

age = person.pop("age")
print(age)
print(person)

print(person.pop("city", "unknown"))  # 없는 키이면 기본값 반환
```

실제 실행 결과:

```text
20
{'name': 'Min'}
unknown
```

`pop("age")`는 `"age": 20` 항목을 제거하고 값인 `20`을 반환합니다. `"city"`는 없으므로 기본값 `"unknown"`을 반환하며 새 항목을 추가하지 않습니다.

## 헷갈리기 쉬운 점

- **`pop()`은 원본을 바꿉니다.** 값만 확인하려면 리스트는 `items[인덱스]`, 딕셔너리는 `person[키]` 또는 `person.get(키)`를 사용합니다.
- 빈 리스트에서 `pop()`을 호출하거나 범위를 벗어난 인덱스를 지정하면 `IndexError`가 발생합니다.
- 딕셔너리에서 없는 키를 기본값 없이 `pop(키)`로 꺼내면 `KeyError`가 발생합니다. 딕셔너리의 `pop()`은 키를 생략할 수 없습니다.
- 리스트의 `pop(인덱스)`와 `remove(값)`는 다릅니다. `remove(값)`는 처음 일치하는 값을 삭제하고 `None`을 반환합니다. 해당 값이 없으면 `ValueError`가 발생합니다.
- `del items[0]`도 항목을 삭제하지만 꺼낸 값을 반환하는 표현식은 아닙니다. 삭제한 값을 사용하려면 `pop()`이 편리합니다.
