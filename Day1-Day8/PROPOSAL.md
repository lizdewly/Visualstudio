# 구현 전 확인할 방명록 설계

작성일: 2026-10-23 / 상태: 사용자 승인 후 구현 완료

아래는 처음 제시한 설계안입니다. 사용자가 후속 요청에서 패키지 및 SQL 저장·조회, HTML 특수문자 처리, 등록 후 목록 이동 방식의 사용을 승인했습니다. 실제 파일과 검증 결과는 [README](README.md)와 [VERIFICATION](VERIFICATION.md)에 기록합니다.

## 추천 구성

**기존 FastAPI + Pydantic + Uvicorn / HTML·CSS / SQLite 한 테이블**

이름과 내용을 입력해 등록하면 같은 화면에서 최신 글을 볼 수 있는 작은 학습용 앱입니다.

## 새로 사용할 요소

| 요소 | 필요 이유 | 설치 여부 |
| --- | --- | --- |
| `python-multipart` | FastAPI의 `Form`으로 브라우저의 HTML form 입력 처리 | 새 외부 패키지 1개, 승인 후 0.0.32 설치 완료 |
| `sqlite3` | 요청한 SQLite 파일 저장과 SQL 실행 | Python 표준 라이브러리 |
| `html.escape` | 방문자가 쓴 `<script>` 같은 문자열을 실행되는 태그가 아닌 글자로 표시 | Python 표준 라이브러리 |
| `string.Template` | 별도 HTML 파일의 지정된 자리에 글 목록과 안내 문구 삽입 | Python 표준 라이브러리 |
| `datetime` | 작성 시각 기록과 한국 시간 표시 | Python 표준 라이브러리 |

`pathlib`, 일반 함수, 조건문, 반복문, Pydantic 검증은 기존 코드에서 사용한 방식으로 유지합니다. 실행되는 SQL 문자열에 사용자 입력을 직접 합치지 않고 `?` 매개변수로 전달합니다. `Template`은 자동 이스케이프 기능이 없으므로 사용자 문자열을 반드시 `html.escape`한 뒤 삽입합니다.

FastAPI `Form`의 공식 안내는 `python-multipart` 설치를 요구합니다. 외부 패키지 추가를 원하지 않는다면 표준 라이브러리 `urllib.parse`로 제한된 URL 인코딩 폼을 직접 읽는 대안이 있지만, 요청 형식과 크기를 직접 검사할 코드가 늘어납니다. [FastAPI Form 문서](https://fastapi.tiangolo.com/tutorial/request-forms/)

## 화면과 데이터

화면 한 장에 제목, 이름 입력, 내용 입력, 등록 버튼, 오류·완료 안내, 글 목록, 이전·다음 링크를 둡니다. 모바일에서는 한 열로 표시합니다.

테이블은 `guestbook` 하나이며 관계나 외래 키는 없습니다.

| 열 | SQLite 타입 | 의미 |
| --- | --- | --- |
| id | INTEGER PRIMARY KEY | 글 번호 |
| name | TEXT NOT NULL | 작성자 이름, 앞뒤 공백 제거 후 1~20자 |
| message | TEXT NOT NULL | 내용, 앞뒤 공백 제거 후 1~500자 |
| created_at | TEXT NOT NULL | 서버가 기록한 작성 시각 |

`INTEGER PRIMARY KEY`를 사용하고 `AUTOINCREMENT`는 사용하지 않는 안입니다. 별도의 사용자 테이블이나 번호 관리 테이블을 만들지 않습니다.

## 확인받을 새 처리 방식

1. 등록 요청 → 입력 검증 → SQL INSERT → 저장 성공 시 HTTP 303 응답 → 목록 GET. 등록 후 새로고침으로 같은 POST가 반복되는 상황을 줄입니다. 빠른 중복 클릭까지 완전히 막는 기능은 아닙니다.
2. 최신순으로 페이지당 10개를 SQL에서 조회합니다. 전체 목록을 매번 메모리에 가져오지 않습니다.
3. 저장은 짧은 트랜잭션으로 처리하고 연결을 닫습니다. 총 글 수 검사와 INSERT는 같은 쓰기 트랜잭션에서 처리합니다.
4. 최대 1,000개 글, 이름 20자, 내용 500자, 요청 본문 16 KiB를 상한으로 두는 안입니다. 한도를 넘으면 기존 글을 지우지 않고 신규 등록을 거부합니다.
5. HTML 특수문자는 이스케이프하고 SQL 입력은 매개변수로 전달합니다.

위 상한은 서비스가 정한 무료 용량이 아니라 앱에서 제안하는 보수적인 제한입니다. 가상 환경·로그·트래픽도 서비스 할당량을 사용하므로 이 제한만으로 무료 운영 전체를 보장할 수는 없습니다.

## 승인 후 만들 파일과 검증

- `main.py`: FastAPI 경로, 입력 검증, 저장·조회·화면 생성 함수.
- `templates/index.html`, `static/style.css`: JavaScript 없는 화면.
- `requirements.txt`: 실행 의존성. 테스트 의존성은 별도 개발용 파일.
- `test_guestbook.py`: 등록, 입력 거부, HTML 이스케이프, SQL 특수문자, 페이지 이동, 단일 테이블, 한도 초과, 재연결 후 보존 검증.
- `.gitignore`: 가상 환경, DB, 캐시 등 실행 중 생성된 파일 제외.
- README와 배포 문서에 실제 실행 명령 및 확인 결과 추가.

Python 파일을 `py -m py_compile`로 구문 검사하고, 격리된 임시 SQLite 파일과 기존 TestClient 방식으로 검증했습니다. 구현은 승인을 받은 후 진행했습니다.
