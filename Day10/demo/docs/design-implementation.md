# design.md 적용 명세

2026-10-27 구현. 원문은 Oura의 마케팅·상품 디자인을 분석한 문서이므로, 게시판에 필요한 시각 원칙과 폼·카드만 적용했다. 브랜드명·상품·장바구니·결제·뉴스레터 UI는 추가하지 않았다.

유료 Editorial New·AkkuratLL 폰트 파일은 제공되지 않아 배포하지 않았다. 외부 CDN과 추가 폰트 다운로드 없이 동작하도록 시스템 글꼴로 대체했다. 한국어 제목은 Batang 계열을 사용하며 운영체제별 글꼴 모양 차이가 있을 수 있다.

사진은 게시판의 핵심 기능에 필요하지 않으므로 외부 상품·라이프스타일 사진을 복제하지 않고 코드로 만든 종이 저널 일러스트를 적용했다. silver 상품 무대·제품 이미지·통계 배지·카루셀은 쓰임이 없어 제외했다.

목록의 게시글 행은 제목만 표시하며 메타데이터나 내용 요약을 추가하지 않았다. 폼은 크림색 위에 밝은 카드로 배치했다. 삭제는 파란 주 CTA 대신 중립색 확인 버튼을 사용한다. 화면의 장식 요소는 보조기술에서 숨겼다.

색상·형태·간격은 `app/static/style.css`, 마크업은 `app/templates/`에 구현했다. 중복 제출 방지는 `app/static/forms.js`의 점진적 보조 기능이며 JavaScript 없이도 핵심 폼은 동작한다.
